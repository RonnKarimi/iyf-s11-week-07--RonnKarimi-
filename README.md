# IYF S11 - Week 07: Local Storage & State Management

## Overview

This repository contains my solutions for **IYF Software Engineering Sprint 11 - Week 07**.

This week's focus was on learning how to build professional JavaScript applications by implementing data persistence using Local Storage and Session Storage, organizing code into modules, improving code quality, debugging effectively, and writing automated tests.

---

## Learning Objectives

By completing this project, I learned how to:

- Store and retrieve data using Local Storage.
- Save JavaScript objects using JSON.
- Use Session Storage for temporary data.
- Manage application state effectively.
- Organize JavaScript code into multiple modules.
- Follow clean code principles.
- Debug applications using browser developer tools.
- Configure ESLint and Prettier.
- Write and run unit tests using Vitest.
- Refactor projects into maintainable code.

## How to Run

1. Clone this repository.

```bash
git clone https://github.com/RonnKarimi/iyf-s11-week-07-RonnKarimi.git
```

2. Open the project folder.

3. Open **index.html** in your browser.

4. To run tests:

```bash
npm install
npm test
```
